# Sound files

Almost every noise in the game is synthesised at runtime in `src/lib/sound.ts`,
so that nothing has to come down the wire on a phone connection. This directory
is the one exception.

## invincible.mp3

The crowd for an unbeaten season — fourteen won, none lost, and the cup. It is
the rarest thing in the game, and no oscillator was going to sell it.

It costs nobody anything: it is fetched only once a run reaches the playoffs,
and only a run that is still unbeaten there will ever play it.
